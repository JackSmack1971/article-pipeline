# Context: SEO E-E-A-T author-credential check has no data source in this pipeline

**Situation:** `article-seo-optimizer`'s On-Page Checklist item 17 requires an author name and
credential visible in the byline or first paragraph. No artifact in the pipeline
(`pipeline_config.json`, `article_spec.md`, or any research artifact) carries an author identity,
and `CLAUDE.md`'s hard constraints prohibit fabricating one ("Never fabricate research, claims,
citations, tool results, approval, or completed stages" — extends to author identity by the same
logic). The check is therefore structurally guaranteed to fail on every run unless resolved
outside the pipeline.

**Observed instance:** Qwen3.8-Max article run, 2026-08-03. Item 17 failed; user was asked and
chose to deliver without a byline, leaving the gap documented in `seo_package.md`'s "E-E-A-T
Gaps" section for the eventual publisher.

**Why this matters:** This will re-surface identically on every future run and consume a gate
interaction each time unless addressed structurally.

**Recommendation:** If author bylines are expected at publication time, add an `author` field
(name + credential/affiliation) to `pipeline_config.json` at TRIAGE or as a project-level default
in `CLAUDE.md`, so SEO can populate it without asking the user mid-pipeline on every article.
